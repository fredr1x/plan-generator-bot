# plan-generator-bot: что сделано, что осталось, план на завтра

Обновлено 02.10.2026. Код запушен в `main` (последний коммит: КТП из PDF).

## Сделано

- **Планы уроков:** профиль, классы, расписание, `/plan`, DOCX по шаблону, ИИ-задания, ценность «Біртұтас тәрбие», кнопки «Короче / Больше заданий / Другой вариант / Другой класс».
- **Учебники:** загрузка PDF утилитой `book-ingest`, ключи ответов кодом, каталог okulyk.kz, привязка к классам, загрузка по одобрению владельца.
- **КТП:** Word (`.docx`, `.doc`) и PDF с текстом читает `gpt-5-mini` частями с проверкой «дословно из файла». Прогоны: Word 68/68, $0,02; PDF 68/68, $0,027.
- **Календарь и даты:** четверти, каникулы, праздники 2026–2027, `/calendar`, расстановка уроков КТП по датам, пересчёт при смене календаря, расписания и «Урок не состоялся».
- **Подготовка планов:** `/week`, `/tomorrow`, `/settings`, вечерний планировщик (предложения / автомат), страницы книги по теме, особые уроки (контрольная, проект, CLIL).

## Не проверено в реальных условиях

1. Скачивание файла КТП из настоящего Telegram (локально читал файл с диска).
2. Вечерний запуск по таймеру, кнопка «Составить все», режим «автомат» (вызывают OpenAI).
3. Загрузка PDF с okulyk.kz через `book-ingest --watch`.
4. Работа на Render под нагрузкой маминых классов.

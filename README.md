# plan-generator-bot

Telegram-бот, который составляет краткосрочные (поурочные) планы уроков и присылает их файлом DOCX.

## Что умеет

- `/start`: профиль учителя (Ф.И.О., школа, предмет, язык планов ru / kk / en, длительность урока).
- `/classes`: классы с количеством учеников (`7 А 25`).
- `/schedule`: недельное расписание (номер урока и класс по дням).
- `/plan`: выбор дня и урока из расписания (или любых классов), затем раздел, тема, цели с кодами, пожелания.
  Данные можно прислать одним сообщением:
  ```
  Раздел: ...
  Тема: ...
  Цели: 7.2.3.1 ...
  ```
- `/history`: прошлые планы, повторная отправка файла.
- Под каждым готовым планом кнопки: «Короче», «Больше заданий», «Другой вариант» и «Тот же урок: другой класс или дата». Последняя спрашивает только день и классы, а на экране проверки появляется «Тот же план без ИИ» (копия без обращения к модели).
- На экране проверки можно изменить дату, классы, раздел, тему, цели и пожелания.
- Меню команд (кнопка «/») регистрируется в Telegram при старте, если задан `BOT_TOKEN`.

Шаблон документа: шапка (раздел, школа, дата, педагог, класс, присутствуют / отсутствуют, тема, цели обучения, цели урока для групп «все / большинство / некоторые») и таблица «Ход урока» (этап и время, действия педагога и ученика, оценивание, ресурсы). Количество присутствующих считается по классам, «отсутствующих» остаётся пустым. Сумма минут по этапам всегда равна длительности урока.

## Как получить план в боте

1. `/start` один раз: Ф.И.О., школа, предмет (список кнопок), длительность урока.
2. `/classes` один раз: `7 А 25`, для 10–11 классов с направлением: `10 А 22 ЕМН` или `11 Б 20 ОГН`.
3. `/schedule` по желанию: по дням, строки вида `1 7А`, `2 7Б`.
4. `/plan`: день → урок из расписания (или классы) → раздел, тема, цели с кодами (можно одним сообщением:
   `Раздел: ...`, `Тема: ...`, `Цели: 1.1.1.1 ...`) → **учебник** (если загружен): страницы вручную (`22` или
   `22-23`), или «🔎 Найти по теме» → экран проверки → «✅ Составить план». Через 20–60 секунд приходит DOCX.
5. Под планом кнопки: «Короче», «Больше заданий», «Другой вариант», «Тот же урок для другого класса».

## Учебники (RAG без векторной базы)

Книги загружает `tools/book-ingest` (на своём компьютере: бот принимает файлы только до 20 МБ). Каждая страница
рендерится в картинку и **один раз** разбирается моделью с картинки: текст, упражнения с ключами ответов (для
открытых вопросов образцы), тексты для чтения, описания картинок. Страницы лежат в Postgres (`books`, `book_pages`).
При `/plan` бот находит страницы по номеру (печатному) или по теме и передаёт модели их данные.

```
./mvnw -f tools/book-ingest/pom.xml package
java -jar tools/book-ingest/target/book-ingest.jar --pdf book.pdf --title "Plus English Grade 7 Student's Book" \
     --subject "English language" --grade 7 --type student --quarters 1-4 --env .env
```

Параметры: `--type student|workbook`, `--track natural|social` (только 10–11 классы), `--quarters 1-4` (или `2`),
`--part "first half"`, `--from/--to`, `--pages 22,24,30-32` (перезагрузить конкретные страницы), `--parallel`.
Повторный запуск пропускает уже загруженные страницы. Цена порядка $0,005 за страницу (книга на 128 страниц ≈ $0,7).
Ключи ответов создаёт модель: открытые задания помечены образцами, аудирование без скрипта «ответа нет».

## Запуск локально

1. Создать бота у @BotFather, получить ключ OpenAI.
2. `cp .env.example .env` и заполнить значения (`ALLOWED_IDS` — Telegram id через запятую).
3. БД: любой Postgres (например Neon). Таблицы создаются Flyway в схеме `plangen`.
4. Запуск: `./mvnw quarkus:dev` (порт из `PORT`).
5. Чтобы Telegram достучался до локального бота, нужен публичный URL (туннель). Затем:
   `https://api.telegram.org/bot<BOT_TOKEN>/setWebhook` с параметрами `url=<публичный URL>/webhook` и `secret_token=<WEBHOOK_SECRET>`.

## Деплой

Docker-образ собирается из `Dockerfile` (например, Render free). Переменные окружения как в `.env.example`, `PORT` задаёт платформа. Health check: `/q/health`.
